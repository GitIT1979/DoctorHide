# DoctorHide

Обезличивание документов: **PDF с текстовым слоем**, DOCX, DOC, RTF, XLSX, XLS, MD/TXT.

Персональные данные закрываются **чёрными** плашками. В PDF скрытый текст физически
удаляется, вставленные изображения под плашкой тоже удаляются — остальной документ
остаётся читаемым и поисковым. В текстовых форматах значения заменяются на `[censored]`.

Картинки и PDF-сканы (без текстового слоя) обрабатываются только при установленном
`indra-ocr`; без него файл → `skipped` с понятной причиной.
Форматы **.doc / .rtf / .xls** конвертируются через LibreOffice во временный
DOCX/текст/XLSX (LibreOffice ищется в PATH и в стандартных местах установки).

## Что скрывается

15 категорий, все включены по умолчанию:

| Ключ | Что закрывается |
|---|---|
| `person` | ФИО, инициалы |
| `identity` | упоминания документов личности (паспорт, в/у, загранпаспорт и т.п.) |
| `codes` | ИНН, КПП, ОГРН/ОГРНИП, ОКПО, ОКТМО, ОКАТО, ОКВЭД, СНИЛС, полис ОМС |
| `address` | индекс, регион, город, улица, дом, квартира, офис |
| `realty` | объекты недвижимости, кадастровый номер, площадь, права |
| `contacts` | телефоны, e-mail, мессенджеры |
| `bank` | счета, карты, БИК, названия банков |
| `finance` | суммы, доходы, зарплата, долги, кредиты, налоги |
| `property` | автомобили, VIN, госномера |
| `employment` | место работы, должность |
| `leisure` | санатории, курорты, отели |
| `birth` | возраст, дата рождения |
| `kinship` | родство |
| `org` | наименования организаций (включая суды) |
| `docno` | номера документов и дел |

В **судебных актах** (режим `judicial`, определяется автоматически) скрывается **всё**
из категорий выше: названия судов, номера дел, ФИО судей и участников, адреса,
идентификаторы имущества, счета и т.д. Обычные даты (решений, поставок, сроков договоров)
по умолчанию **не** скрываются — только возраст и явная «дата рождения».

## Установка

```bash
python -m pip install -r requirements.txt
```

Требуется Python 3.9+.
Для **.doc / .rtf / .xls** — LibreOffice (`soffice`); достаточно установить его —
PATH не обязателен, берётся и `C:\Program Files\LibreOffice\program\soffice.exe`.
Для PDF — пакет `pymupdf`.

## Использование

```bash
python doctorhide.py "документ.pdf"          # PDF -> документ_hidden.pdf
python doctorhide.py "акт.docx"              # DOCX -> акт_hidden.md
python doctorhide.py "таблица.xlsx"          # XLSX -> таблица_hidden.md
python doctorhide.py "заявление.md"
python doctorhide.py "решение.pdf" --mode judicial
python doctorhide.py "папка/" --report report.json
python doctorhide.py "акт.docx" --keep-format   # результат .docx с [censored]
python doctorhide.py "старый.doc"               # DOC/RTF → через LibreOffice → .md
python doctorhide.py "расчет.xls"               # XLS → через LibreOffice → .md
```

`-o/--out` задаёт имя результата и допустим только для одного входного файла.
При пакетной обработке результаты сохраняются в текущий каталог.

Выбор категорий:

```bash
python doctorhide.py --list-categories
python doctorhide.py doc.pdf --keep org docno
python doctorhide.py doc.pdf --only person address
python doctorhide.py doc.pdf --ask
```

## Проверка и отчёт

Пропущенные файлы (скан, картинка, чужой формат) **не исчезают**: в JSON-отчёте
и в консоли есть `status: skipped` и `reason` (например, `pdf без текстового слоя`
или `формат не поддерживается (изображение/скан)`).

```bash
python doctorhide.py in/ --report report.json --json
```

## Числа, таблицы, вертикальный текст

- **Суммы и числа** маскируются только при контексте (валюта, д.р., документ) в том же
  предложении; годы судебных решений, статьи и страницы без такого контекста не трогаются.
- **Markdown-таблицы**: money/PII red-flag в таблице → числа по всей таблице.
- **PDF**: колонки по **x**, строки и пары «подпись→значение» по **y**; вертикально
  набранный текст (столбик глифов) склеивается перед детекцией.
- **Банк**: 20-значные счета (в т.ч. с пробелами), IBAN, SWIFT, карты.

## Ограничения

- **Формы PDF**: значения полей форм маскируются, вложенные файлы удаляются, но
  сама форма (виджеты) остаётся редактируемой. Сложные виджеты с нестроковыми
  значениями (кнопки, подписи) не обезличиваются.
- ФИО ищутся эвристиками: редкая фамилия без отчества может не распознаться.
- Фамилия без имени или инициалов внутри предложения не скрывается — чтобы не закрывать
  обычные слова; отдельным словом на своей строке (значение поля в бланке) скрывается.
- ФИО и e-mail, разорванные переносом строки в текстовых файлах (MD/TXT),
  могут не распознаться; в PDF переносы обрабатываются.
- Фотографии и другие картинки удаляются только под плашкой: если лицо не попало
  в область найденных данных, изображение остаётся.
- Сканы PDF собираются заново постранично: страница рендерится в 200 dpi, при
  необходимости выпрямляется и сохраняется как JPEG с уже выжженными плашками.
  Поэтому ориентация и `/Rotate` больше не мешают (ценой размера файла).
- **.xls / .doc / .rtf** требуют LibreOffice: он ищется в PATH и в стандартных папках
  установки; без него файл → `skipped` с причиной. Битый файл, который LibreOffice
  конвертирует в мусор, тоже помечается пропущенным, а не выдаётся пустым.
- Картинки (PNG/JPG/TIFF) обрабатываются в любой ориентации: страница выпрямляется,
  результат — PDF с чёрными плашками.
- PDF только с текстовым слоем; сканы и изображения не обрабатываются.
- Даты событий (не рождения) по умолчанию не скрываются.

Подробные правила — в [ПРАВИЛА_АНОНИМИЗАЦИИ.md](ПРАВИЛА_АНОНИМИЗАЦИИ.md).

## OCR (сканы и изображения)

Сканы PDF и картинки обрабатываются через [Indra OCR](https://github.com/datalab-to/indra),
если он установлен. Без него такие файлы попадают в отчёт как `skipped`
(«установите indra-ocr»).

Установка:
```
pip install indra-ocr
```
При первом запуске модели (~76 МБ) скачиваются с Hugging Face.

Поддерживаются: PDF (с текстом и сканы), PNG, JPG, TIFF, BMP, WebP, DOCX, DOC, RTF, XLSX, MD, TXT.
