# DoctorHide

Обезличивание документов: PDF, DOCX, MD/TXT и изображения.

Персональные данные закрываются чёрными плашками — как в кино про «совершенно секретно»
(белые плашки — флаг `--white-bars`): в PDF скрытый текст при этом физически удаляется,
остальной документ остаётся читаемым и поисковым; в сканах и картинках плашки выжигаются
в пикселях. Вставленные растры под плашкой тоже вычищаются — фотографию или QR-код из
готового файла не вытащить.

## Что скрывается

15 категорий, все включены по умолчанию:

| Ключ | Что закрывается |
|---|---|
| `person` | ФИО, инициалы — в том числе разорванное по строкам ФИО и двойные имена/фамилии |
| `identity` | паспорт, водительское удостоверение, загранпаспорт, военный билет, свидетельство о рождении, полис ОМС |
| `codes` | ИНН, КПП, ОГРН/ОГРНИП, ОКПО, ОКТМО, ОКАТО, ОКВЭД, СНИЛС |
| `address` | индекс, регион, город, улица, дом, квартира, офис |
| `realty` | квартиры, дома, участки, гаражи; кадастровый номер, площадь; собственность, аренда |
| `contacts` | телефоны (в т.ч. без кода страны и разорванные переносом строки), e-mail, мессенджеры |
| `bank` | счета (в т.ч. сгруппированные пробелами), карты, БИК, названия банков |
| `finance` | суммы, доходы, зарплата, выручка, долги, кредиты, налоги |
| `property` | автомобили, VIN, госномера |
| `employment` | место работы, работодатель, должность |
| `leisure` | санатории, курорты, отели, путёвки |
| `birth` | возраст и **все даты**: рождения, выдачи документов, событий — числом и прописью |
| `kinship` | родство |
| `org` | наименования организаций |
| `docno` | номера документов |

Бланки личности (паспорт, свидетельства, СНИЛС, полис ОМС, справка о регистрации) на сканах —
закрываются полем целиком, открытой остаётся только строка с названием документа. Причина: на фото
бланка OCR читает фамилию как «Sanwa», и всё нераспознанное осталось бы открытым. Если не читается
и заголовок, лист закрывается полностью — в отчёте это видно. В анкетах и таблицах значение
закрывается вместе с ячейкой: подпись слева — значение справа, подпись сверху — значение снизу.

В судебных актах (определяется автоматически) сохраняются названия судов, ФИО судей,
секретарей, представителей сторон, свидетелей, экспертов, прокуроров и иных участников,
наименования организаций-участников и номер дела; скрываются адреса, города, возраст.

## Установка

```bash
python -m pip install -r requirements.txt
# OCR: Tesseract 5 с языками rus и eng
#   Windows: winget install UB-Mannheim.TesseractOCR
```

Русская модель и конфиги Tesseract подхватываются из `_tools/tessdata`, если папка есть рядом
со скриптом; иначе используется системная установка.

## Использование

```bash
python doctorhide.py "документ.pdf"          # PDF -> документ_hidden.pdf
python doctorhide.py "акт.docx"              # DOCX -> акт_hidden.md
python doctorhide.py "паспорт.png"           # картинка -> паспорт_hidden.png
python doctorhide.py "решение.pdf" --mode judicial
python doctorhide.py "папка/" --report report.json
python doctorhide.py "документ.pdf" --white-bars  # белые плашки вместо чёрных
```

Выбор категорий:

```bash
python doctorhide.py --list-categories            # что вообще скрывается
python doctorhide.py doc.pdf --keep org docno     # оставить открытым
python doctorhide.py doc.pdf --only person address
python doctorhide.py doc.pdf --ask                # показать найденное и спросить
```

Полный список ключей: `python doctorhide.py --help`.

## Проверка

После обработки PDF переоткрывается и проверяется: скрытых значений нет ни в извлечённом тексте,
ни в сырых потоках файла. Метаданные очищаются.

Самопроверка приложения — собирает фикстуры и прогоняет все сценарии через CLI:

```bash
python tests/selftest.py      # 81 проверка: md, docx, pdf, скан, картинка, судебный акт,
                              # разорванная OCR фамилия, ФИО через разрыв строк, двойные имена,
                              # все даты, таблицы, бланк с фотографией, QR в картинке, --keep/--ask
```

В интерфейсе пачка заканчивается архивом, внутри которого лежит `_ОТЧЁТ.txt`: по каждому файлу —
готово или нет, сколько плашек, какие категории всё-таки найдены в результате. Файл, который
не удалось обработать, виден в отчёте с причиной, а не пропадает из выдачи.

## Ограничения

- ФИО ищутся эвристиками (отчество, суффиксы фамилий, справочник имён, ролевые маркеры):
  редкая фамилия без отчества может не распознаться — критичные документы просматривайте глазами.
  Разорванную OCR фамилию («ЯКОВЛЕВА-ЗАВАЛЬ» + «ЕВСКАЯ») программа склеивает обратно.
- OCR ошибается на косых и шумных сканах; мелкий шрифт (мельче ~6 pt) может не распознаться.
- Даты скрываются все; если какие-то даты нужно сохранить (сроки договора), используйте
  `--keep birth` или `--ask`.

Подробные правила — в [ПРАВИЛА_АНОНИМИЗАЦИИ.md](ПРАВИЛА_АНОНИМИЗАЦИИ.md).

## Структура

```

gui/server.py               локальный сервер интерфейса

```

## Имена файлов

Имя результата всегда получает суффикс `_hidden`:

| Исходное имя | Результат |
|---|---|
| `Заявление о раннем уходе Саши 14.10.2026.md` | `Заявление о раннем уходе_hidden.md` |
| `Заметка без данных.md` | `Заметка без данных_hidden.md` |

Из названия убираются ФИО и уменьшительные имена, даты, номера, адреса, названия организаций.
Если после чистки остаётся меньше трёх букв, имя становится `document`. Поведение отключается
флагом `--keep-name`.

сканлайны, кнопки с `►` и `▓`. Шпионская часть — красная полоса «СОВЕРШЕННО СЕКРЕТНО»,
гриф «ДОСЬЕ · УРОВЕНЬ 4», строка «СЖЕЧЬ ПОСЛЕ ПРОЧТЕНИЯ», номер досье в шапке.
