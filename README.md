# DoctorHide

Обезличивание документов: **PDF с текстовым слоем**, DOCX, XLSX, MD/TXT.

Персональные данные закрываются **чёрными** плашками. В PDF скрытый текст физически
удаляется, вставленные изображения под плашкой тоже удаляются — остальной документ
остаётся читаемым и поисковым. В текстовых форматах значения заменяются на `[censored]`.

Картинки и PDF-сканы (без текстового слоя) **не поддерживаются**: файл попадает в отчёт
со статусом `skipped` и причиной.

## Что скрывается

15 категорий, все включены по умолчанию:

| Ключ | Что закрывается |
|---|---|
| `person` | ФИО, инициалы |
| `identity` | упоминания документов личности (паспорт, в/у, загранпаспорт и т.п.) |
| `codes` | ИНН, КПП, ОГРН/ОГРНИП, ОКПО, ОКТМО, ОКАТО, ОКВЭД, СНИЛС, полис ОМС |
| `address` | индекс, регион, город, улица, дом, квартира, офис |
| `realty` | объекты недвижимости, кадастровый номер, площадь, права |
| `contacts` | телефоны, e-mail, мессенджеры |
| `bank` | счета, карты, БИК, названия банков |
| `finance` | суммы, доходы, зарплата, долги, кредиты, налоги |
| `property` | автомобили, VIN, госномера |
| `employment` | место работы, должность |
| `leisure` | санатории, курорты, отели |
| `birth` | возраст, дата рождения |
| `kinship` | родство |
| `org` | наименования организаций (включая суды) |
| `docno` | номера документов и дел |

В **судебных актах** (режим `judicial`, определяется автоматически) скрывается **всё**
из категорий выше: названия судов, номера дел, ФИО судей и участников, адреса,
идентификаторы имущества, счета и т.д. Обычные даты (решений, поставок, сроков договоров)
по умолчанию **не** скрываются — только возраст и явная «дата рождения».

## Установка

```bash
python -m pip install -r requirements.txt
```

Требуется Python 3.9+.

## Использование

```bash
python doctorhide.py "документ.pdf"          # PDF -> документ_hidden.pdf
python doctorhide.py "акт.docx"              # DOCX -> акт_hidden.md
python doctorhide.py "таблица.xlsx"          # XLSX -> таблица_hidden.md
python doctorhide.py "заявление.md"
python doctorhide.py "решение.pdf" --mode judicial
python doctorhide.py "папка/" --report report.json
python doctorhide.py "акт.docx" --keep-format   # результат .txt вместо .md
```

Выбор категорий:

```bash
python doctorhide.py --list-categories
python doctorhide.py doc.pdf --keep org docno
python doctorhide.py doc.pdf --only person address
python doctorhide.py doc.pdf --ask
```

## Проверка и отчёт

Пропущенные файлы (скан, картинка, чужой формат) **не исчезают**: в JSON-отчёте
и в консоли есть `status: skipped` и `reason` (например, `pdf без текстового слоя`
или `формат не поддерживается (изображение/скан)`).

```bash
python doctorhide.py in/ --report report.json --json
```

## Ограничения

- ФИО ищутся эвристиками: редкая фамилия без отчества может не распознаться.
- PDF только с текстовым слоем; сканы и изображения не обрабатываются.
- Даты событий (не рождения) по умолчанию не скрываются.

Подробные правила — в [ПРАВИЛА_АНОНИМИЗАЦИИ.md](ПРАВИЛА_АНОНИМИЗАЦИИ.md).
