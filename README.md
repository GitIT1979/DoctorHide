# DoctorHide

Обезличивание документов: **PDF с текстовым слоем**, DOCX, DOC, RTF, XLSX, XLS, MD/TXT,
а также сканы и картинки (OCR). Персональные данные закрываются **чёрными** плашками;
в текстовых форматах значения заменяются на `[censored]`.

## Две формы приложения

| Папка | Что внутри | Кому |
|---|---|---|
| [`app/`](app/README.md) | готовый `DoctorHide.exe` — Windows, Python не нужен | если нужно просто обезличить документы |
| [`source/`](source/README.md) | исходный код, тесты, сборка exe | запуск на Python, доработка, пересборка |

## Быстрый старт

**Готовое приложение**

1. Откройте [`app/DoctorHide.exe`](app/README.md).
2. В браузере: перетащите файлы → «ANONYMIZE THIS!» → «СКАЧАТЬ».

**Из исходников**

1. `cd source`
2. `python -m pip install -r requirements.txt`
3. `python doctorhide.py "документ.pdf"` (CLI) или `python gui/server.py` (интерфейс).

Подробности — в README каждой папки. Правила и категории —
[`source/ПРАВИЛА_АНОНИМИЗАЦИИ.md`](source/ПРАВИЛА_АНОНИМИЗАЦИИ.md).
