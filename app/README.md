# DoctorHide — готовое приложение

`DoctorHide.exe` — самостоятельная сборка для Windows: Python не нужен.
Внутри интерфейс в браузере, командная строка и OCR для сканов и картинок.

## Что нужно

- Windows 10/11, 64-бит.
- Для `.doc / .rtf / .xls` — установленный LibreOffice (иначе эти файлы пропускаются с причиной).
- При первом распознавании сканов — интернет: OCR-модели (~76 МБ) скачиваются в кэш пользователя.

## Вариант 1. Интерфейс

1. Запустите `DoctorHide.exe` двойным щелчком.
2. Откроется браузер: `http://127.0.0.1:8765/` (если порт занят — следующий свободный). Окно консоли не закрывайте — это сервер.
3. Перетащите файлы в окно или нажмите «ФАЙЛЫ» / «ПАПКА» (до 100 файлов, до 200 МБ каждый).
4. Нажмите «ANONYMIZE THIS!» и дождитесь статуса «ГОТОВО» у файлов.
5. Скачайте результат кнопкой «СКАЧАТЬ» или весь архив — «Скачать .zip».
6. Очередь, результаты и журнал — в папке `_gui_work` рядом с exe; после закрытия её можно удалить.

Нужен конкретный порт? `DoctorHide.exe --port 8766`.
Доступ с другого компьютера: `DoctorHide.exe --host 0.0.0.0 --allow-remote`
(без пароля и TLS — только в доверенной сети).

## Вариант 2. Командная строка

1. Откройте PowerShell в папке с exe (Shift + правый клик → «Открыть окно PowerShell здесь»).
2. Один файл: `.\DoctorHide.exe "документ.pdf"` — в текущей папке появится `документ_hidden.pdf`.
3. Папка: `.\DoctorHide.exe "C:\docs" --report report.json` — результаты в текущей папке.
4. Категории: `--keep org docno` (оставить открытыми) или `--only person address` (скрывать только эти).
5. Отчёт: `--report report.json` или `--json` (печать в консоль).
6. Код возврата: `0` — всё обработано, `1` — были пропуски или ошибки.

## Ограничения

- Файл не подписан: Windows SmartScreen может предупредить при первом запуске.
- Сборка «onefile»: при старте распаковывается во временную папку, первый запуск дольше обычного.
- Первый OCR-запуск дольше — скачиваются модели.

## Обновление

Соберите новую версию из исходников (см. [`../source/README.md`](../source/README.md),
раздел «Сборка exe») и замените `DoctorHide.exe` в этой папке.
