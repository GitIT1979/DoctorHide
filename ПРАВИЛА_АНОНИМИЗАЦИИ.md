# DoctorHide — правила обезличивания

Программа: `doctorhide.py` (Python 3.9+, PyMuPDF, python-docx, openpyxl).

## Форматы

| Вход | Выход | Механика |
|---|---|---|
| PDF с текстовым слоем | `<имя>_hidden.pdf` | Чёрные плашки. Текст под ними **удаляется**. Изображения под плашкой **удаляются**. |
| PDF без текстового слоя | — | Пропуск, в отчёте: `pdf без текстового слоя`. |
| PNG/JPEG/TIFF/… | — | Не поддерживается; в отчёте: `формат не поддерживается (изображение/скан)`. |
| DOCX | `<имя>_hidden.md` (или `.txt` при `--keep-format`) | Текст → Markdown → `[censored]`. |
| XLSX/XLS | то же | Листы → Markdown-таблицы → `[censored]`. |
| MD/TXT | `<имя>_hidden.<ext>` | `[censored]`. |

## Категории

Скрываются по умолчанию все. Список: `python doctorhide.py --list-categories`.

| Ключ | Что скрывается |
|---|---|
| `person` | ФИО, инициалы |
| `identity` | Упоминания документов личности в тексте |
| `codes` | ИНН, КПП, ОГРН, ОКПО, ОКТМО, ОКАТО, ОКВЭД, СНИЛС, ОМС |
| `address` | Адреса |
| `realty` | Недвижимость, кадастр, площадь, права |
| `contacts` | Телефоны, e-mail, мессенджеры |
| `bank` | Счета, карты, БИК, банки |
| `finance` | Суммы, доходы, долги, кредиты, налоги |
| `property` | Авто, VIN, госномера |
| `employment` | Работа, должность |
| `leisure` | Санатории, отели, курорты |
| `birth` | Возраст, дата рождения |
| `kinship` | Родство |
| `org` | Организации и суды |
| `docno` | Номера документов и дел |

## Судебные акты

Режим `--mode auto` включает `judicial` по маркерам (решение, дело №, истец/ответчик, судья…).

В судебном режиме **скрывается всё** из категорий (суды, номера дел, ФИО участников,
адреса, имущество, счета, идентификаторы). Обычные даты (решений, поставок, сроков
договоров) **не** скрываются — только возраст и явная «дата рождения».

## Выбор пользователя

```
python doctorhide.py --list-categories
python doctorhide.py doc.pdf --keep org docno
python doctorhide.py doc.pdf --only person address
python doctorhide.py doc.pdf --ask
python doctorhide.py doc.docx --keep-format
```

## Отчёт

Пропущенные файлы видны в JSON (`status: skipped`, `reason`) и в консоли.
