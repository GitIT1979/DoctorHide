# DoctorHide — правила обезличивания

Программа: `doctorhide.py` (Python 3.9+, PyMuPDF, python-docx, openpyxl).

## Форматы

| Вход | Выход | Механика |
|---|---|---|
| PDF с текстовым слоем | `<имя>_hidden.pdf` | Чёрные плашки. Текст под ними **удаляется**. Изображения под плашкой **удаляются**. Метаданные PDF (Author, Title, Producer, XMP) **очищаются**. |
| PDF без текстового слоя (скан) | `<имя>_hidden.pdf` | При установленном `indra-ocr`: OCR через Indra → redaction по координатам строк. Страницы пересобираются выпрямленными. Без `indra-ocr` — пропуск. |
| PNG/JPEG/TIFF/BMP/WebP | `<имя>_hidden.pdf` | При установленном `indra-ocr`: OCR + redaction + EXIF-очистка. Без `indra-ocr` — пропуск. |
| DOCX | `<имя>_hidden.md` (или `.docx` при `--keep-format`) | Текст → Markdown → `[censored]`. При `--keep-format`: метаданные core.xml/app.xml **очищаются**. |
| DOC/RTF | `<имя>_hidden.md` | Через LibreOffice → текст → `[censored]`. |
| XLSX/XLS | то же | Листы → Markdown-таблицы → `[censored]`. |
| MD/TXT | `<имя>_hidden.<ext>` | `[censored]`. |

## Категории

Скрываются по умолчанию все. Список: `python doctorhide.py --list-categories`.

| Ключ | Что скрывается |
|---|---|
| `person` | ФИО, инициалы |
| `identity` | Упоминания документов личности в тексте |
| `codes` | ИНН, КПП, ОГРН, ОКПО, ОКТМО, ОКАТО, ОКВЭД, СНИЛС, ОМС |
| `address` | Адреса |
| `realty` | Недвижимость, кадастр, площадь, права |
| `contacts` | Телефоны, e-mail, мессенджеры |
| `bank` | Счета, карты, БИК, банки |
| `finance` | Суммы, доходы, долги, кредиты, налоги |
| `property` | Авто, VIN, госномера |
| `employment` | Работа, должность |
| `leisure` | Санатории, отели, курорты |
| `birth` | Возраст, дата рождения |
| `kinship` | Родство |
| `org` | Организации и суды |
| `docno` | Номера документов и дел |

## Судебные акты

Режим `--mode auto` включает `judicial` по маркерам (решение, дело №, истец/ответчик, судья…).

В судебном режиме **скрывается всё** из категорий (суды, номера дел, ФИО участников,
адреса, имущество, счета, идентификаторы). Обычные даты (решений, поставок, сроков
договоров) **не** скрываются — только возраст и явная «дата рождения».

Внимание: judicial-режим включает все категории (как и document по умолчанию).
`--keep` в judicial-режиме всё равно отключает категории — если нужно гарантированно
скрыть всё, не используйте `--keep`.

## Метаданные

При обработке очищаются:
- **PDF**: doc.info (Author, Title, Subject, Keywords, Creator, Producer, CreationDate, ModDate), XMP metadata stream, Information Dictionary.
- **DOCX/XLSX** (при `--keep-format`): docProps/core.xml (creator, lastModifiedBy, created, modified), docProps/app.xml (Application, Company, Manager). docProps/custom.xml удаляется.
- **Изображения**: EXIF (GPS-координаты, DateTimeOriginal, Artist, Copyright, BodySerialNumber и др.) извлекается как текст и анонимизируется через `[censored]`. В выходной PDF EXIF не переносится.

## Выбор пользователя

```
python doctorhide.py --list-categories
python doctorhide.py doc.pdf --keep org docno
python doctorhide.py doc.pdf --only person address
python doctorhide.py doc.pdf --ask
python doctorhide.py doc.docx --keep-format
```

## Отчёт

Пропущенные файлы видны в JSON (`status: skipped`, `reason`) и в консоли.
