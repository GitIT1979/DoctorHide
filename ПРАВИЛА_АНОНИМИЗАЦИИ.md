# DoctorHide — правила обезличивания

Программа: `doctorhide.py` (Python 3.9+, PyMuPDF, Pillow, python-docx, Tesseract 5 с `rus`+`eng`).

## Форматы и что происходит с файлом

| Вход | Выход | Механика |
|---|---|---|
| PDF с текстовым слоем | `<имя>_hidden.pdf` | Чёрные плашки (белые — `--white-bars`). Скрытый текст **удаляется** из файла (не «заклеивается») — под плашкой искать нечего. Остальной текст остаётся текстом: файл читается, ищется, копируется. |
| PDF-скан (без текстового слоя) | `<имя>_hidden.pdf` | Страница распознаётся Tesseract, области выжигаются в том же растре и страница собирается обратно 1:1 по вёрстке. Распознанный текст кладётся невидимым слоем — файл остаётся поисковым; отключить: `--no-text-layer`. |
| PNG / JPEG / TIFF / BMP / WEBP | `<имя>_hidden.<ext>` | Tesseract → плашки выжигаются в пикселях, формат и размер сохраняются. QR-коды и штрихкоды в растре закрываются тем же сканером, что и для сканов PDF. |
| DOCX | `<имя>_hidden.md` | Конвертация в Markdown (заголовки, списки, таблицы), значения → `[censored]`. |
| MD / TXT | `<имя>_hidden.<ext>` | Значения → `[censored]`. |

Плашки ставятся как в кино: ровный прямоугольник — чёрный по умолчанию, белый по флагу
`--white-bars`. Подчёркивания и границы таблиц, случайно попавшие под белую плашку,
восстанавливаются поверх белого. Картинки под плашкой не просто закрашиваются: пиксели
вставленных растров тоже вычищаются — вытащить фотографию или QR-код из готового PDF нельзя.

## Что закрывается и как

| Что | Как |
|---|---|
| Паспорт, свидетельство о рождении / браке / удочерении, СНИЛС, полис ОМС, справка о регистрации | Скан бланка закрывается полем целиком — открытой остаётся только строка с названием документа. Построчно такие документы закрывать нельзя: OCR читает фамилию на фото как «Sanwa», и всё, что не распознано, осталось бы открытым. Если не читается и заголовок (фото паспорта под углом), лист закрывается полностью, а в отчёте появляется пометка. |
| Анкеты, выписки, таблицы | Значение закрывается вместе с ячейкой: подпись слева — значение справа, подпись сверху — значение снизу. Сама подпись остаётся читаемой. |
| ФИО, разорванное по строкам | Фамилия на одной строке, имя и отчество на следующих — даже через пустую строку: стык соседних коротких строк проверяется на пары «фамилия + имя/отчество» и «имя + фамилия». Двойные имена и фамилии («Софья-Анна», «Сергеев-Кузнецов») закрываются целиком. |
| Рукописная дата после «Дата выдачи» | Закрывается вся правая часть строки до края текста: OCR читает рукопись обрывками. |
| Заверительная надпись «ВЕРНО» внизу листа | Закрывается блок под ней — подпись, дата и фамилия заверяющего. |
| E-mail и телефон, разорванные переносом строки | «ivanov@» в конце строки и «example.ru» в начале следующей склеиваются и закрываются вместе; телефон, разбитый на две строки, — аналогично. |

## Категории

Скрываются по умолчанию все. Список: `python doctorhide.py --list-categories`.

| Ключ | Что скрывается |
|---|---|
| `person` | ФИО: фамилия, имя, отчество, инициалы, ФИО после ролевых маркеров — в том числе разорванное по строкам (даже через пустую строку) и двойные имена/фамилии |
| `identity` | Паспорт (серия/номер, код подразделения), водительское удостоверение, загранпаспорт, военный билет, свидетельство о рождении, полис ОМС |
| `codes` | ИНН (с проверкой контрольного числа), КПП, ОГРН/ОГРНИП, ОКПО, ОКТМО, ОКАТО, ОКВЭД, СНИЛС |
| `address` | Индекс, регион, город, улица, дом, корпус, квартира, офис |
| `realty` | Квартиры, дома, участки, гаражи, машино-места; кадастровый номер; площадь; права — собственность, аренда, безвозмездное пользование |
| `contacts` | Телефоны (в т.ч. без кода страны «495 123-45-67» и разорванные переносом строки), e-mail, мессенджеры |
| `bank` | Расчётные и корреспондентские счета (в т.ч. сгруппированные пробелами «4070 2810 …»), карты, БИК, названия банков |
| `finance` | Суммы, доходы, зарплата, выручка, задолженность, кредиты, налоги, пенсии |
| `property` | Автомобили и прочее имущество, VIN, госномера |
| `employment` | Место работы, работодатель, должность |
| `leisure` | Санатории, курорты, отели, путёвки |
| `birth` | Возраст («45 лет») и **все даты**: рождения, выдачи документов, событий — числом («15.03.2024»), коротким годом («01.07.25»), прописью и с словом «год/года/году» |
| `kinship` | Сын, дочь, мать, отец, супруг(а), брат, сестра, опекун + имя |
| `org` | Наименования организаций: ООО/АО/ПАО/ИП, госорганы, инспекции, управления |
| `docno` | Номера документов «№ …», длинные номера (сертификаты) |

## Судебные акты

Режим включается сам (`--mode auto`) по маркерам: решение, постановление, приговор, «дело №»,
истец/ответчик, прокурор, судья, апелляция/кассация.

В судебном акте **не скрываются**: названия судов, ФИО судей, секретарей, представителей сторон,
свидетелей, экспертов, прокуроров и иных участников, наименования организаций-участников,
номер дела.

**Скрываются**: возраст, все даты, адреса, города. ИНН/ОГРН/СНИЛС/паспорт скрываются
по умолчанию; флаг `--court-keep-ids` оставляет их (типично при публикации актов с ИНН организаций).

## Выбор пользователя

```powershell
python doctorhide.py --list-categories              # что вообще скрывается
python doctorhide.py doc.pdf --keep org docno       # эти категории оставить открытыми
python doctorhide.py doc.pdf --only person address  # скрыть только эти
python doctorhide.py doc.pdf --ask                  # показать найденное и спросить
```

`--ask` печатает, какие категории и сколько раз найдены, и спрашивает, что оставить открытым.
Enter — скрыть всё.

## Запуск

```powershell
python doctorhide.py "паспорт.png"                     # картинка
python doctorhide.py "договор.docx"                    # docx -> md
python doctorhide.py "акт.pdf" --dpi 400               # плотнее OCR для скана
python doctorhide.py "решение.pdf" --mode judicial     # принудительно судебный акт
python doctorhide.py "папка\"                          # папка целиком
python doctorhide.py "docs\*.pdf" --report report.json # маска + JSON-отчёт
```

Ключи: `--mode auto|judicial|document`, `--ocr auto|always|never`, `--dpi`, `--placeholder`,
`--white-bars`, `--no-bar-border`, `--keep`, `--only`, `--ask`, `--keep-meta`,
`--court-keep-ids`, `--report`, `--json`, `-o`.

Tesseract: ставится отдельно (`winget install UB-Mannheim.TesseractOCR`), русская модель
и конфиги лежат в `_tools\tessdata` и подхватываются автоматически.

## Проверка результата

- После обработки PDF переоткрывается и проверяется извлечённый текст: скрытых значений быть не должно
  (`leftover` в отчёте). Заголовок бланка в проверку не входит — он остаётся намеренно.
- Отдельно проверяются сырые потоки PDF, включая распакованные, — там значений тоже нет.
- Метаданные (автор, producer, даты) очищаются, если не указан `--keep-meta`.
- В пачке через интерфейс каждый файл попадает в `_ОТЧЁТ.txt` внутри архива: готово или нет,
  сколько плашек, какие категории всё-таки найдены в результате. Файл с ошибкой больше
  не исчезает из выдачи молча — он есть в отчёте вместе с причиной.

## Ограничения

- ФИО определяются эвристиками: отчество, суффиксы фамилий, справочник имён, ролевые маркеры.
  Редкая фамилия без отчества и без маркера может не распознаться — критичные документы
  просматривайте глазами (или используйте `--ask`, чтобы видеть, что найдено).
  Разорванную OCR фамилию («ЯКОВЛЕВА-ЗАВАЛЬ» + «ЕВСКАЯ») программа склеивает обратно.
- Правила «ключевое слово + значение» намеренно требуют рядом цифру/название, чтобы не съедать
  заголовки («налогоплательщика», «Паспорт гражданина Российской Федерации» в сноске).
- OCR ошибается на косых и шумных сканах. Пятна краски, которые Tesseract пропустил
  (мелкий шрифт в углу, печать, подпись), дочитываются отдельными фрагментами; но символы
  мельче ~6 pt могут остаться нераспознанными — плашки на этом месте не будет.
- В сканах и картинках плашки выжигаются в растре: пиксели уничтожены, но вместе с ними может
  пострадать фон под плашкой (линия рамки и т. п.).
- Даты скрываются все. Если даты нужно сохранить (сроки действия договора), оставьте категорию
  открытой: `--keep birth` или `--ask`.
- На скане бланка личности закрывается всё поле: распознать на фото отдельные значения нереально, а оставить открытым — значит оставить фамилию. Открытой остаётся только строка заголовка, и то если OCR её прочитал.
- Фотографию на скане ищем по пятну полутонов; на бланках её закрывает общая плашка поля.

## QR-коды и штрихкоды

Закрываются плашкой вместе с остальными данными:

- во вставленных изображениях PDF — по признаку «почти чёрно-белая картинка с плотным
  рисунком» и пропорциям (квадрат для QR, широкий прямоугольник для штрихкода);
- в сканах и в отдельных изображениях (PNG/JPEG и т. д.) — по трём маркерам QR с пропорцией
  1:1:3:1:1 и по повторяющемуся узору вертикальных полос в соседних строках (штрихкод);
- изображение, занимающее больше половины страницы, кодом не считается — это сам скан.

Метод эвристический: экзотические коды (Aztec, DataMatrix) могут не распознаться.

## Имена файлов

Название обезличивается только тогда, когда содержит то же, что скрывается в тексте документа:
ФИО и уменьшительные имена, даты, номера, адреса, названия организаций, телефоны.

- результат всегда получает суффикс `_hidden` — и когда имя пришлось чистить, и когда чистить было нечего;
- после чистки меньше трёх букв -> `document_hidden.<ext>`.

Суффикс один: раньше чистые имена получали `_anon`, и в пачке это выглядело как два разных
результата обработки.

Отключить правило: `--keep-name`.
